BUILD (Manually) -----------------------

- Create CMakeLists.txt
- Enter build directory
- Enter command 'cmake -G "MinGW Makefiles" ..' to address code space (And using MinGW)
- Execute makefiles via 'mingw32-make.exe'

BUILD (Automatically) -------------------

Wichtig: Muss sourceDir statt workspaceFolder setzen als Variable
- Create CMakeLists.txt
- Enter command 'cmake --preset default' to build using CMake Preset
- Execute makefiles via 'cmake --build build'

BUILD (VS Code) ------------------------

- VSCode Command 'CMake: Select Configure Preset' & Choose Preset
- Click on Build in CMake Menu


CROSS-COMPILE

- Install Compiler (Trixie) from https://gnutoolchains.com/raspberry/
- Create new Toolchain-file in project (-> pi-toolchain.cmake)
- Create CMakePresets entry to link toolchain-file in new preset
- VSCode Command 'CMake: Select Configure Preset' & Choose Preset
- Click on Build in CMake Menu
